# Ask how the user does it today

**Recorded:** 2026-11-04, outside a sprint
**Roles:** all, and the Product Manager and the Manager before they brief an Investigator

## What

Before investigating how something works or could work for the user, ask how they do it today, and look at what their own projects already show. Investigate only what that leaves open.

## Why

Planning a simpler setup that had to work in cloud sessions, an Investigator was sent to read the providers' docs on how skills and roles could reach a cloud container. It came back with inferences and a list of tests only the user could run. The user was already running a sprint as roles in a Claude Code cloud session: their environment's setup script cloned this repository and ran setup. One question and a look at that project's git answered what the investigation could only infer.

## When it applies

Briefing an Investigator, or putting tests to the user, about the user's own environment: cloud sessions, a second machine, a provider's behaviour in their projects.
