## Commissioning a review

- **Whoever commissioned the work commissions its review**, never the author under review: the Manager for THOUGHTS, a PRD and a PLAN, the Implementation Manager for code. The author does not choose when it is reviewed and writes no part of the reviewer's brief.
- **The brief** names what is reviewed, by file or by branch and fork point, what it is checked against, and the working directory.
- **The report** leads with a verdict, `blocking findings` or `no blocking findings`, and marks each finding `blocking` or `minor`. Send the findings to the author, or to a Coder for code. A reviewer's verdict passes no gate.
