## Questions to the user

`process.questions`, `process.recommend` (`true`, `false`, `accept`) and `process.density` (`brief`, `full`) say how you put questions to the user and how much they read, as the `prd-implementation` skill's conventions.md says under "Questions to the user", where a value the user states in the session wins. Read them once a session with its `python scripts/settings.py process --project <project root>`.
