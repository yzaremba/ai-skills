## Reading hand-backs

A dispatched role ends each of its turns with a hand-back for you: a state marker, one line, and quotes of the user as the agent recorded them. It is all you see of that turn, not what the user typed to the agent. Ready is not approved, and a quote passes a gate only as Gates says.

**A missing hand-back.** If the user says an agent is done and none has arrived, follow up with the agent and ask for it. A quote that comes back then passes nothing.
