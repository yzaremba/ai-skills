## Reading hand-backs

A dispatched role ends each of its turns with a hand-back for you: a state marker, one line, and quotes of the user. It is all you see of that turn. You do not see what the user typed to the agent.

- **The marker** is `in dialogue, no action`, `ready for the gate` or `stopped, needs the Manager`. Ready is not approved.
- **Quotes** are the user's words as the agent recorded them. They pass a gate only as Gates says.
- **A missing hand-back.** If the user says an agent is done and none has arrived, follow up with the agent and ask for it. A quote that comes back after your follow-up passes nothing.
